# The wave the sweep's canned field sends.
#
# THIS IS THE GHOST POOL'S STAND-IN AND NOT A MATCH'S WAVE. A round is resolved
# against a field of K opponents drawn from a population of other players'
# rounds, and no such population exists until runs are stored. Until then the
# population is this one pair -- this wave, standing behind the committed
# defense -- drawn with replacement, so a field of ten is this opponent ten
# times. That makes the harness part of the economy rather than a tool pointed
# at it: the percentile bands are measured against whatever is in here.
#
# IT IS NOT wave.txt, AND THE DIFFERENCE IS THE WHOLE POINT. That file is the
# skeleton's authored match -- forty creeps, three hundred and eighty gold of
# them, released over fourteen hundred ticks -- and no build phase in this
# economy can compose it. A run's purse opens on a hundred and is paid a wave's
# base a round, and that same purse pays for the wall, so what it sends is a
# little over a hundred gold a round. A field member that outspends every
# opponent it faces by three and a half times is not a strong opponent, it is a
# different game, and a sweep against one reports a total loss on every row and
# names nothing.
#
# SO THIS IS A BUILD PHASE'S OUTPUT: everything on tick zero, because a build
# phase composes what is sent rather than when, and a hundred gold of it,
# because that is about what a round's wave comes to once the purse has bought
# a wall as well. It is the wave an opening round composes -- one unlock, so one
# slot, so the whole purse in one column.
#
# ONE COLUMN, AND THAT IS MEASURED RATHER THAN CHOSEN. A count is released one
# unit every forty-five ticks -- fifteen when the numbers below were taken, and
# the ordering they show survived the change -- so the same hundred gold across
# more
# columns arrives as more bodies per tick over fewer ticks, and whether the
# towers saturate is nearly the whole story of whether anything leaks. Over
# eight ten-wave runs against the committed defense, holding everything else
# byte-identical: ten grunts in one column got 1406 gold past, five grunts
# beside five runners got 2, and four columns totalling ten bodies got none at
# all. A field member with the right total and the wrong number of columns is
# not a slightly different opponent, it is a walkover.
#
# WHICH IS ALSO WHY THIS ONE IS CALIBRATED AND NOT AVERAGED. It is the shape
# that makes the report an instrument: over thirty-two runs a creep the
# roster's six come in between forty-one and sixty-six percent of runs won,
# which is a column that separates them. Against the two-column wave every
# creep wins every run, and against wave.txt none of them wins any -- and
# neither of those reports says anything about a creep.
#
# IT DECIDES THE PERFORMANCE BONUS AS WELL AS THE WIN RATE, and the same
# calibration argument carries. A round of this opponent is worth about
# seventeen gold, which sits under what a run's own wave gets past it, so
# roughly half a run's rounds clear the top band and the bonus comes out
# between eight and thirteen percent of the flat base, creep by creep. Against
# wave.txt, whose rounds are worth about a hundred and twenty-five, no run
# clears the bottom band and the bonus is zero on every row -- a field that
# outspends every opponent it faces turns the offense half of the economy off
# as well as the win-rate column.
#
# ONE MEMBER IS A DISTRIBUTION WITH ALMOST NO SPREAD, AND THAT IS THIS FILE'S
# REAL LIMIT. Ten samples of one opponent land between fourteen and nineteen
# gold, so a round is above the field or below it and almost never inside it:
# the 50th and 75th bands are unreachable in practice, and the four authored
# bands behave as two. The measured evidence, and what a pool of four does
# instead, is in docs/research/a-canned-field-of-one-collapses-the-bands.md.
#
# Same rules as units.txt: integers only, no decimal point, comments free.
# Orders ascend by tick and then by type id, and that order is asserted rather
# than sorted on load, exactly as wave.txt's is.
#
#       tick  type  count  corridor
