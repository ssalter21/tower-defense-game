# The wave the sweep's canned field sends.
#
# THIS IS THE GHOST POOL'S STAND-IN AND NOT A MATCH'S WAVE. A round is resolved
# against a field of K opponents drawn from a population of other players'
# rounds, and no such population exists until runs are stored. Until then the
# population is this one pair -- this wave, standing behind the committed
# defense -- drawn with replacement, so a field of ten is this opponent ten
# times. That makes the harness part of the economy rather than a tool pointed
# at it: the percentile bands are measured against whatever is in here.
#
# IT IS NOT wave.txt, AND THE DIFFERENCE IS THE WHOLE POINT. That file is the
# skeleton's authored match -- forty creeps, three hundred and eighty sauce of
# them, released over fourteen hundred ticks -- and no build phase in this
# economy can compose it. A run's purse opens on one wave's base and is paid
# one wave's base a wave, so what it sends is a little over a hundred sauce a
# round. A field member that outspends every opponent it faces by three and a
# half times is not a strong opponent, it is a different game, and a sweep
# against one reports a total loss on every row and names nothing.
#
# SO THIS IS A BUILD PHASE'S OUTPUT: everything on tick zero, because a build
# phase composes what is sent rather than when, and a hundred sauce of it,
# because that is what a purse holds when a round comes round. It is the wave
# an opening round composes -- one unlock, so one slot, so the whole purse in
# one column.
#
# ONE COLUMN, AND THAT IS MEASURED RATHER THAN CHOSEN. A count is released one
# unit every fifteen ticks, so the same hundred sauce spread across more
# columns arrives at more bodies per tick over fewer ticks. Against the
# committed defense that is nearly the whole story of whether anything leaks:
# a hundred sauce in one column of ten grunts gets about a hundred and forty
# sauce past a round, and the same hundred sauce as five grunts beside five
# runners gets past two sauce over a whole ten-wave run. Two columns of five
# are simply killed. A field member with the right total and the wrong number
# of columns is not a slightly different opponent, it is a walkover.
#
# WHICH IS ALSO WHY THIS ONE IS CALIBRATED AND NOT AVERAGED. It is the shape
# that makes the report an instrument: against it the roster's six creeps come
# in between nothing and thirty-seven percent of runs won, which is a column
# that separates them. Against the two-column wave every creep wins every run
# and against wave.txt none of them wins any, and neither of those reports says
# anything about a creep.
#
# Same rules as units.txt: integers only, no decimal point, comments free.
# Orders ascend by tick and then by type id, and that order is asserted rather
# than sorted on load, exactly as wave.txt's is.
#
#       tick  type  count  corridor
