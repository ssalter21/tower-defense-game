# The anchor schedule.
#
# TWO LAYERS, AND THE SPLIT IS THE POINT. The SHAPE -- which waves are anchors,
# which tier each draws from, which one opens the steep counter, and what
# answers it -- is authored here and holds for a whole rotation, so preparation
# has a constant to be a skill about. The FILLING -- which three of a tier's
# game changers sit on that anchor's menu -- is drawn per run and revealed at
# run start, so a map fixed for a week does not go stale in it. A schedule
# fixed on both layers is solved by Tuesday; one drawn on both has nothing to
# prepare against.
#
# Same rules as units.txt and ruleset.txt: integers only, no decimal point,
# comments free. The content hash folds the parsed integers in FIELD ORDER
# rather than the bytes, so reindenting a column, rewrapping this comment or
# converting the line endings moves nothing, and changing one number moves it.
#
# THIS IS A TABLE AND NOT A SET OF CONSTANTS, so the sweep can sweep a schedule
# the way it already sweeps a map.
#
# WAVE SLOT WIDTH IS NOWHERE IN THIS FILE, and its absence is the design. A
# round's width is the ruleset's starting width plus its per-anchor step once
# for every anchor at or before that round, which on the shape below reads
# 2 2 3 3 3 4 4 4 5 5 across ten waves. A second series authored here would be
# a copy of that derivation, free to drift from it the first time somebody
# moves an anchor and forgets the copy -- so a 'slots' row in this file is
# refused by name rather than read.
#
# THESE NUMBERS ARE PROVISIONAL BY CONSTRUCTION, priced against the one-hex
# corridor that is the only board there is.
#
# ---------------------------------------------------------------------------
# THE SHAPE
#
#         anchor  wave  tier  opens  counter  from
#
# wave    : which wave of the run this anchor falls on. ANCHORS ASCEND STRICTLY
#           and live in the interior: wave 1 is the starting state, and the last
#           wave is the payoff round where what was taken gets spent.
# tier    : which pool this anchor's three game changers are drawn from. TIERS
#           ASCEND STRICTLY WITH THE WAVES, so nothing hands out a late-grade
#           creep at wave 3 where nothing yet answers it.
# opens   : plain, or steep for the anchor that opens the steep counter. EXACTLY
#           ONE ANCHOR PER SHAPE IS STEEP AND IT IS THE LAST ONE -- one missed
#           buy then punishes rather than eliminates, and a run does not turn on
#           a single purchase.
# counter : the unit type that answers this anchor. It is a placed unit, because
#           an anchor opens offense and never defense: the threat can be seen
#           coming and the preparation happens on the other side of the board.
# from    : the wave that counter is purchasable from. STRICTLY BEFORE THE WAVE
#           IT ANSWERS, and refused at load otherwise -- an answer that first
#           appears at the wave it is needed for is a forced simultaneous buy,
#           which deletes the axis this whole schedule exists to restore. Wave
#           nine's answer is late enough that eight rounds of income have paid
#           for it.

anchor        3     1  plain        3     1
anchor        6     2  plain        3     1
anchor        9     3  steep        4     8

# ---------------------------------------------------------------------------
# THE TIER POOLS
#
#         changer  id  label  tier  unit  bonusVsTag
#
# id         : the identity a filling is drawn by. Ids ascend strictly down this
#              file, and a game changer belongs to ONE TIER AND THEREFORE ONE
#              ANCHOR'S MENU, so nobody doubles down on the same one twice.
# label      : for people and for error messages. Nothing branches on it and
#              renaming one does not move the content hash.
# unit       : the body it fields, and EVERY ONE OF THESE IS A PLACEHOLDER. The
#              nine authored game changers a shape wants are the roster's
#              content bill and are not written yet; until they are, a menu is
#              filled from the creeps that exist so that the machinery around it
#              can be built, tested and swept. Four to a pool rather than three,
#              so that drawing a menu is a draw rather than a copy.
# bonusVsTag : what this anchor's counter adds to its rolled damage BEFORE the
#              type chart and armour, when it shoots this creep. Zero everywhere
#              but the steep anchor's pool, and refused at load if that is not
#              so. 825 is three times the mortar's average roll of 275, so a
#              prepared shot lands about four times as hard as an unprepared
#              one: STEEP RATHER THAN BINARY, so mis-preparing punishes instead
#              of eliminating. The bonus joins the hit rather than bypassing it,
#              which is what makes a high-armour creep blunt its own counter.
