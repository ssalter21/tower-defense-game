# The whole Engineer line told apart by the size of its turret, and nothing else.
#
# THE DECISION THIS DRAWS. Sam signed two things on 10 Sep 2026: the Mortar's
# turret at *1.50, and no second prop for the Artificer -- "just scale the tower
# twice", so the tier-2 rung becomes a scale as well. That reading puts the
# Artificer at the step between, *1.25, since the bracket is even steps and
# tier 3 is 1.50. This file is that reading drawn, so the reading can be checked
# rather than assumed.
#
# WHAT IT HAS TO SHOW, AND IT IS NOT WHAT THE OLD FRAMES SHOWED. Every earlier
# mortar-turret-* frame answers "can you see this turret got bigger than the
# board ships it". This one answers a harder question: standing three cells
# apart under one camera, can a player tell *1.25 from *1.00 AND *1.50 from
# *1.25 -- two steps, each half the size of the one the sheets measured. If the
# middle step does not read, the line has three rungs and two visible states.
#
# ROWS 35, 36 AND 37 ARE THE THREE RUNGS. 35 stays at the size it imports at,
# because tier 1 is the thing the other two have to be heavier than.
#
# NOTHING THE GAME SHIPS FROM MOVES. Applied to a copy of the wired art for the
# length of one run. See UnitArtFile.cs.
