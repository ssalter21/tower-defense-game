# The 31 characters the roster expansion assigns, as a candidate set.
#
# WHAT THIS IS FOR. docs/roster-expansion-proposal.md assigns 31 of the
# collection's 61 rigged characters to a tower line or a creep row, and every
# one of those assignments is a placeholder until Sam has looked at it. This
# renders them:
#
#     tools/capture-armed-roster.ps1 -SetFile docs/roster-expansion-candidates.txt
#
# One PNG per line into docs/frames/roster (ignored, never committed), plus
# candidates-sheet.png and candidates-manifest.txt. Nothing here is an oracle
# and no test reads it. Edit a line, run it again, look again.
#
# HOW A LINE READS. Six whitespace-separated fields:
#
#     side  name  model  right-hand  left-hand  clip
#
#   side        tower or creep -- which of the two shipped views draws it.
#   name        what the PNG is called. The model's own name, not a unit name:
#               one model serves up to three tiers and no row exists yet.
#   model       the character, relative to client/Assets/Art/.
#   right-hand  what hangs off handslot.r, or - for an empty hand.
#   left-hand   what hangs off handslot.l, or - for an empty hand.
#   clip        the pose. Unqualified names are searched for in the
#               Rig_Medium_* banks; a Large-rig character must say its bank,
#               as Rig_Large_General/Idle_A, because Idle_A, Walking_A and
#               Death_A exist in both rigs and the wrong one draws without
#               complaining.
#
# A held prop may carry a turn, written path@x,y,z in Euler degrees. Every
# weapon in these packs is authored for the right hand, so a bow in the off
# hand needs @0,180,0, and a staff hangs head-down from the fist until
# @0,0,-90 stands it up. Both numbers are the ones MatchSceneBuilder already
# carries for the live rows.
#
# ONE LINE PER MODEL, SO ONE TIER'S LOOK. A model serves up to three tiers and
# the proposal gives each tier its own Looks column, but a character can only
# be photographed holding one thing at a time. Each line takes the look that is
# NEW -- the thing nobody has signed off yet -- and where a model is live, the
# props the match already draws it with. Four props the proposal names are
# therefore not rendered here, and are the second thing to ask for if the first
# sheet leaves a question open: paladin_book (Blessing, Paladin tier 3),
# Cleric_Mace (Bishop, tier 2), staff (Sorcerer, tier 2) and
# Skeleton_Shield_Small_A (the live Skeleton, id 12, whose model is the
# Minion's).
#
# FIVE PLACES THIS DEPARTS FROM THE PROPOSAL, EACH FLAGGED AT ITS LINE.
#   - The Frost Wight takes FrostGolem_Axe_Large. It is a Large-rig body and
#     the proposal names the medium axe, which is hand-sized on it. The Golem,
#     the Black Knight and the Abomination were already named _Large.
#   - Two rows name a backpack -- Tiefling_SwordsBackpack and Hoarder_Backpack
#     -- which is worn on the spine and has no hand socket; the character's own
#     sword stands in.
#   - The Barbarian_Large is posed in the two-handed guard, not the Melee_2H_
#     Slam its capstone is named for. See its line.
#   - The Plant Warrior takes the strung bow export rather than PlantWarrior_
#     Bow, matching the live Ranger.
#   - The Marksman appears twice, once with his rifle and once with the
#     crossbow the proposal asks about, because that is the comparison being
#     put up. 32 lines, 31 characters.
