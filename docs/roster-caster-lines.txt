# The Cleric, Mage and Druid lines as they are now bound, as a set.
#
# WHAT THIS IS FOR. The same question docs/roster-melee-lines.txt asks of the
# other three lines: whether the nine rungs read as three lines of three once
# each row is wearing the atlas, holding the props and playing the clip its
# binding gives it. A rung is told apart from the rung below it by colour, by a
# prop or by a second model, and none of those three can be seen on a sheet of
# one character per model.
#
#     tools/capture-armed-roster.ps1 -SetFile docs/roster-caster-lines.txt
#
# One PNG per line into docs/frames/roster, plus candidates-sheet.png and
# candidates-manifest.txt. Nothing here is an oracle and no test reads it.
# Edit a line, run it again, look again. The one committed copy is
# docs/frames/roster/caster-lines-sheet.png, under a name the tool does not
# write, because every candidate run rewrites candidates-sheet.png.
#
# HOW A LINE READS. The eight fields docs/roster-expansion-candidates.txt's
# header writes out:
#
#     side  name  model  right-hand  left-hand  clip  [texture [beside]]
#
# THIS TRANSCRIBES THE BINDINGS AND DOES NOT DECIDE THEM. Every model, prop,
# atlas, turn and beside prop below is the one MatchSceneBuilder and
# Tests.Fixtures.ChosenArt bind for that row, which is what docs/roster.md
# signs. A line here that disagrees with those tables is this file being wrong,
# not the tables.
#
# THE POSE IS EACH ROW'S IDLE, AND NOTHING HERE IS FRAMING. A set line carries
# one clip and a row carries three, so what is shown is the clip a row stands
# in between shots -- the pose a player sees most of. All nine of these rows
# are posed, so unlike the three Paladin rows on the melee sheet none of them
# needed a clip invented to photograph it. Where roster.md names a clip on one
# of these lines it is the swing -- Ranged_Magic_Shoot for the Cleric and the
# Druid -- and the swing is the windup, not the idle. The windup and backswing
# NUMBERS on the Cleric and Druid blocks are still that page's `_`, and that
# ask stands.
#
# TWO THINGS HERE ARE ASKS FOR roster.md RATHER THAN FOR THE EYE. That page
# does not say where Cleric_Tome goes when the Bishop's mace arrives, so the
# mace takes the hand it was in and the tome is put down -- moving it to the
# off hand would be inventing an assignment rather than reading one. And the
# Elder is colour and nothing else, against that page's own "tier 2 is colour
# plus a prop": its Elder block names druid_texture_alt_A, no prop, and
# `Open -- none`. The rows below are bound as their blocks are written.
#
# A RUNG CARRIES UP WHAT THE RUNG BELOW IT HELD, AND WHAT ITS Looks LINE NAMES
# REPLACES WHAT WAS IN THAT HAND. So the Elder and the Overgrowth carry the
# Druid's staff, which neither of their lines repeats, and the Bishop's mace
# takes the hand the Cleric's tome was in. A colour does not carry up at all:
# it is one of the three things that tell a rung apart, and roster.md gives
# tier 3 the second model instead wherever one exists -- which is why the
# Unravel wears the atlas the Lorekeeper imports with rather than the
# Sorcerer's. That character ships no alternate atlas, and the Sorcerer's
# belongs to a different character's UVs.
