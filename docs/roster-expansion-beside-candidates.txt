# The four props that stand beside a tower, as a candidate set.
#
# WHAT THIS IS FOR. docs/roster.md signs four looks that are not held in a
# hand: the Engineer's turret, the Paladin's statue, the Cleric's font and the
# Druid's bare weirwood. Each stands on the tile beside its tower. The trunk
# form of the Druid's tree was picked on 5 September 2026 from a turntable
# sheet -- Tree_Bare_1_C_Color8, issue #274 -- and a turntable at uniform
# framing says nothing about how big a tree should be next to a standing man.
# That is what this set is for.
#
#     tools/capture-armed-roster.ps1 -SetFile docs/roster-expansion-beside-candidates.txt
#
# One PNG per line into docs/frames/roster, plus candidates-sheet.png and
# candidates-manifest.txt. Nothing here is an oracle. Edit a line, run it
# again, look again.
#
# HOW A LINE READS. The same fields docs/roster-expansion-candidates.txt uses,
# and its header is where they are written out. The eighth is the one this set
# is about:
#
#     side  name  model  right-hand  left-hand  clip  texture  beside
#
#   beside  what stands on the ground beside the tower, relative to
#           client/Assets/Art/, with *scale for how big it is drawn. A held
#           prop is authored beside the character that holds it and comes in
#           at the right size; these are scenery off other packs and do not.
#           The offset is not in this file: everything beside a tower stands
#           one tile away, which is BesideProp.NextTile, which is the board's
#           own column pitch.
#
# THE SIZES BELOW WERE MEASURED, NOT GUESSED. The capture logs a [beside] line
# per tile giving the prop's drawn height, its footprint and where its centre
# sits. Drawn at their own imported size, on a board whose tiles are 2.0 across
# the flats:
#
#   turret_base      1.13 m tall, 1.00 x 1.13 on the ground   *1
#   ammo_crate       0.46 m tall, 0.57 x 0.49                 *1
#   paladin_statue   2.55 m tall, 1.60 x 1.09                 *1
#   Cleric_Font      0.81 m tall, 1.44 x 1.44                 *1
#   Tree_Bare_1_C    5.26 m tall, 3.74 x 2.07                 *0.55
#
# The first four are authored in the same packs as the characters they stand
# beside and land inside their own tile at 1. The trees are scenery for a
# forest: 1_C spreads 3.74 across, which is nearly two tiles, and reaches back
# through the Druid himself. 0.55 brings that spread to 2.06 -- the tile it is
# standing on -- and leaves it 2.89 tall, half again the Druid's own height.
# All six trees take that one number so the comparison is like for like.
#
# The character's own atlas covers the character only. A beside prop is its own
# import off its own pack's atlas -- the forest texture for the trees, the
# paladin's for the statue -- so nothing is painted over it, and that is what
# stops a Cleric_Font drawn against a cleric's character sheet coming out as
# confetti.
#
# TEN LINES, FOUR QUESTIONS. Six of them are the same Druid holding the same
# staff beside each of the pack's six Color8 bare trees, which is the pick
# re-asked at the scale it will actually be drawn at. The other four are the
# turret, the statue and the font beside the characters roster.md gives them
# to, each at the tier its Looks line signs.
