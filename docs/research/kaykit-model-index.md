# The KayKit model index

Every distinct model name in **The Complete KayKit Collection v6.1**, pack by pack. This is the lookup table:
the question it answers is "does KayKit have a *thing*, and what is the file called". The reasoning, the rigs,
the clip lists and the triangle counts are in
**[What is actually inside The Complete KayKit Collection v6.1](kaykit-collection-inventory.md)**.

**Read from the archive**, not from a listing — names are the `.gltf` file stems in each pack's
`Assets/gltf/` folder, which match the `.fbx` stems exactly. The file to import is the one in
`Assets/fbx(unity)/`.

**Colour variants are collapsed.** Forest Nature ships every model in eight colourways (`_Color1` … `_Color8`)
and Platformer and Medieval Hexagon in blue/red/green/yellow; those suffixes are written `<colour>` here.
Expanding them back gives the 4,324 `.gltf` files actually in the bundle. Collapsed, there are **2,252
distinct models**.

**Rigged characters are not in this file.** They ship as `.glb`, not `.gltf`, and are listed with their rig and
triangle count in [the inventory](kaykit-collection-inventory.md#6-the-61-characters-with-rig-and-triangle-count).
What appears below for the five character packs is their weapons, accessories and scene props.
