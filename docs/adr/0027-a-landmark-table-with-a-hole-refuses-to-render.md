# A landmark table with a hole in it refuses to render

Every row of the landmark table is a moment the sit-down checklist sends somebody to look at. If a run produces no candidate for a row, the table refuses to render and names the row rather than emitting a table with a gap in it.

## Consequences

A content change that stops anything ever being orphaned, or stops any creep ever passing another, has changed the match into one the checklist cannot be written against. The useful moment to find that out is while regenerating the table, by name — not at the sit-down, holding a row that points nowhere.

Two of the six match events exist only so the table can be derived from a run (ADR-0008).
